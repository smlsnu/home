# basic_codes

연구실 구성원이 공통으로 쓰는 코드를 모으는 곳입니다. `lab-members` 팀이면 누구나 추가·수정할 수 있습니다.

## 무엇을 올리나요

- 자주 쓰는 유틸리티 (파일 입출력, 좌표 변환, 날짜 처리 등)
- 위성/재분석 자료 읽기 예제
- 지도·시계열 등 표준 시각화 템플릿
- 신입 연구원용 입문 노트북

## 규칙

- 파일 하나가 하나의 목적을 갖도록 작성합니다.
- 파일 맨 위에 **무엇을 하는 코드인지, 어떤 입력이 필요한지** 주석으로 남깁니다.
- 절대 경로(`/home/사용자명/...`)는 파일 상단에 변수로 모아 두어 다른 사람이 쉽게 바꿀 수 있게 합니다.
- 데이터 파일은 함께 올리지 않습니다. 어디서 받는 자료인지 주석으로 설명합니다.

## 권장 구조

```
basic_codes/
├── io/          # 자료 읽기·쓰기
├── plotting/    # 시각화 템플릿
├── utils/       # 좌표·시간·통계 유틸
└── tutorials/   # 입문 노트북
```
