# SML SNU — 안내 저장소

서울대학교 **인공위성기상기후연구실(Satellite Meteorology Laboratory, SML)** 의 안내 저장소입니다.

이 저장소에는 **코드가 없습니다.** 연구실 GitHub 사용 규칙, Git 사용법, 저장소 목록 등
안내 문서만 들어 있으며, 그 내용이 아래 사이트로 발행됩니다.

**https://smlsnu.github.io/home/**

---

## 저장소 목록

| 저장소 | 공개 | 내용 | 수정 가능 |
|--------|------|------|-----------|
| [`home`](https://github.com/smlsnu/home) | public | 안내 문서 (이 저장소) | `lab-members` |
| [`basic-codes`](https://github.com/smlsnu/basic-codes) | private | 공용 유틸리티 · 시각화 템플릿 · 입문 예제 | `lab-members` |
| [`team-rain`](https://github.com/smlsnu/team-rain) | private | rain 팀 코드 | `team-rain` |
| [`team-tq`](https://github.com/smlsnu/team-tq) | private | tq 팀 코드 | `team-tq` |
| [`team-rt`](https://github.com/smlsnu/team-rt) | private | rt 팀 코드 | `team-rt` |
| [`team-polar`](https://github.com/smlsnu/team-polar) | private | polar 팀 코드 | `team-polar` |
| [`team-env`](https://github.com/smlsnu/team-env) | private | env 팀 코드 | `team-env` |

- 팀 저장소는 **해당 팀만 수정**할 수 있습니다.
- 연구실 구성원은 **모든 저장소를 읽을 수** 있습니다.

## 처음 오셨다면

1. `smlsnu` 조직 초대를 수락합니다.
2. [시작하기](https://smlsnu.github.io/home/getting-started/) 를 따라 환경을 준비합니다.
3. [Git 사용법](https://smlsnu.github.io/home/git-guide/) 을 읽고 작업 흐름을 익힙니다.
4. [코드 작성 규칙](https://smlsnu.github.io/home/conventions/) 을 확인합니다.

## 문서 수정

`docs/` 안의 마크다운 파일을 고치고 `main` 에 push하면 몇 분 안에 사이트에 반영됩니다.
자세한 방법은 [CONTRIBUTING.md](CONTRIBUTING.md) 를 참고하세요.

## 문의

- 저장소 권한 · 팀 관련 — 조직 Owner
- 팀 참여 — 해당 팀장
