# project_codes

프로젝트별 분석 코드를 모으는 곳입니다. **프로젝트마다 하위 폴더 하나**를 사용합니다.

## 접근 권한

이 폴더 아래는 저장소 규칙(ruleset)으로 보호되어 있어, **해당 프로젝트 팀에 속한 사람만 수정·삭제**할 수 있습니다.
읽기는 누구나 가능합니다.

| 폴더 | 담당 팀 |
|------|---------|
| [`tpw/`](tpw/) | `project-tpw` |

## 새 프로젝트를 시작하려면

조직 Owner에게 아래를 요청하세요.

1. 팀 생성 (`project-<이름>`)
2. 저장소 ruleset의 bypass 목록에 해당 팀 추가
3. `project_codes/<이름>/` 폴더 생성

## 각 프로젝트 폴더에 반드시 포함할 것

- `README.md` — 프로젝트 목적, 사용 자료, 실행 순서, 담당자
- 스크립트 실행 순서를 알 수 있는 번호 체계 또는 설명
- 필요한 외부 데이터의 위치와 획득 방법
