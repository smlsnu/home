## basic_codes/

연구실 구성원이 공통으로 쓰는 코드. `lab-members` 팀이면 누구나 추가·수정할 수 있습니다.

**올리는 것**

- 자주 쓰는 유틸리티 (파일 입출력, 좌표 변환, 날짜 처리)
- 위성/재분석 자료 읽기 예제
- 지도·시계열 등 표준 시각화 템플릿
- 신입 연구원용 입문 노트북

**권장 구조**

```
basic_codes/
├── io/          # 자료 읽기·쓰기
├── plotting/    # 시각화 템플릿
├── utils/       # 좌표·시간·통계 유틸
└── tutorials/   # 입문 노트북
```

## project_codes/

프로젝트별 분석 코드. **프로젝트마다 하위 폴더 하나**를 씁니다.

| 폴더 | 담당 팀 |
|------|---------|
| `tpw/` | `project-tpw` |

이 폴더 아래는 저장소 규칙으로 보호되어 있어 **해당 팀만 수정·삭제**할 수 있습니다. 읽기는 누구나 가능합니다.

각 프로젝트 폴더에는 다음을 반드시 포함하세요.

- `README.md` — 목적, 사용 자료, 실행 순서, 담당자
- 실행 순서를 알 수 있는 번호 체계 또는 설명
- 필요한 외부 데이터의 위치와 획득 방법

### 새 프로젝트 추가

조직 Owner에게 요청하세요.

1. 팀 생성 (`project-<이름>`)
2. 저장소 ruleset의 bypass 목록에 팀 추가
3. `project_codes/<이름>/` 폴더 생성

## 코드 작성 권장 사항

- 파일 상단에 **무엇을 하는 코드인지, 어떤 입력이 필요한지** 주석으로 명시
- 절대 경로는 파일 상단에 변수로 모아 두어 다른 사람이 쉽게 바꿀 수 있게 작성

```python
# 경로 설정 — 환경에 맞게 수정
DATA_DIR = '/home/username/data/ssmi'
OUT_DIR  = '/home/username/result'
```

- 데이터 파일은 함께 올리지 않고, 어디서 받는 자료인지 주석으로 설명
