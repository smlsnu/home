# SML_SNU

서울대학교 **위성기상실험실(Satellite Meteorology Laboratory, SML)** 공용 코드 저장소 안내 사이트입니다.

이곳은 연구실 구성원이 코드를 공유하고 프로젝트 진행 방식을 아카이빙하기 위한 공간입니다.
SML의 발전과 연구 능력 향상을 위해 여러분의 적극적인 참여를 부탁드립니다.

[:material-github: 저장소 바로가기](https://github.com/smlsnu/SML_SNU){ .md-button .md-button--primary }

## 저장소 한눈에 보기

| 폴더 | 내용 | 수정 가능 |
|------|------|-----------|
| `basic_codes/` | 공용 유틸리티, 입문 예제, 시각화 템플릿 | `lab-members` 팀 |
| `project_codes/` | 프로젝트별 분석 코드 | 각 프로젝트 팀 |
| `docs/` | 이 사이트의 소스 | `lab-members` 팀 |

!!! warning "이 저장소는 공개(public)입니다"
    누구나 코드를 열람할 수 있습니다. API 키, 비밀번호, 개인정보, 미공개 자료를 절대 커밋하지 마세요.
