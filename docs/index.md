## 저장소 목록

| 저장소 | 공개 | 내용 | 수정 가능 |
|--------|------|------|-----------|
| [`home`](https://github.com/smlsnu/home) | public | 안내 문서 (이 사이트의 소스) | `lab-members` |
| [`basic-codes`](https://github.com/smlsnu/basic-codes) | private | 공용 유틸리티 · 시각화 템플릿 · 입문 예제 | `lab-members` |
| [`team-rain`](https://github.com/smlsnu/team-rain) | private | rain 팀 코드 | `team-rain` |
| [`team-tq`](https://github.com/smlsnu/team-tq) | private | tq 팀 코드 | `team-tq` |
| [`team-rt`](https://github.com/smlsnu/team-rt) | private | rt 팀 코드 | `team-rt` |
| [`team-polar`](https://github.com/smlsnu/team-polar) | private | polar 팀 코드 | `team-polar` |
| [`team-env`](https://github.com/smlsnu/team-env) | private | env 팀 코드 | `team-env` |

- 팀 저장소는 **해당 팀만 수정**할 수 있습니다.
- 연구실 구성원은 **모든 저장소를 읽을 수** 있습니다.

## 반드시 지킬 세 가지

!!! danger "데이터 파일은 올리지 않습니다"
    `.pkl` `.h5` `.nc` `.gz` 등은 `.gitignore` 로 막아 두었습니다.
    저장소에 올라가는 것은 **코드와 결과 그림**뿐입니다.

!!! warning "`home` 저장소만 공개되어 있습니다"
    문서 사이트 발행을 위해 이 저장소만 public 입니다.
    코드 · 데이터 · API 키 · 미공개 연구 내용을 이곳에 두지 마세요.

!!! tip "작업 시작 전에는 항상 Pull"
    이 습관 하나로 충돌의 대부분이 예방됩니다.
